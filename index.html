Personal Drive Backup

Personal Drive Backup 是一个仅供账户所有者本人使用的本地自动备份流程，使用开源命令行工具 rclone 将指定 Windows 文件夹中的资料复制到用户本人授权的 Google Drive 账户。

用途及功能

此流程在用户自己的 Windows 电脑上运行。它通过 Google Drive API 检查文件状态、创建文件夹，以及上传或更新文件。用户可以自行设定备份目录与执行频率。这里介绍的是个人配置，不提供面向公众的云存储或代管服务。

数据使用

备份文件直接通过本机 rclone 程序传输到用户授权的 Google Drive。OAuth 授权信息存储在用户电脑上的 rclone 配置中。本网站只是说明页面，不要求用户在此输入 Google 密码，不接收备份文件，也不提供 OAuth 授权回调服务。
